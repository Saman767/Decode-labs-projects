# Brew & Bloom — Cafe Landing Page

A static cafe landing page built with HTML, CSS, and vanilla JavaScript.
Developed as Project 1 for the DecodeLabs Frontend Development Industrial Training Kit (Batch 2026).

---

## Live Demo

> Open `index.html` in your browser or use VS Code Live Server.

---

## Project Structure

```
cafe-project/
├── index.html      # Main HTML structure
├── style.css       # All styling and layout
├── script.js       # Scroll reveal animation
└── README.md       # Project documentation
```

---

## Features

- Fully responsive navbar with smooth scroll navigation
- Hero section with full-width background image and overlay
- About section with two-column grid layout
- Menu section with 4 item cards
- Footer with contact information
- Scroll reveal animation on all sections

---

## Tech Stack

- HTML5 (semantic tags)
- CSS3 (Flexbox, Grid, custom properties)
- Vanilla JavaScript (Intersection Observer API)
- Google Fonts — Playfair Display + Lato
